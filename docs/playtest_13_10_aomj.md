**PLAYTEST 6: memory garden, zones (v5)**

Amélie, Mathilde, Joséphine (11) and Olivia (4), with Zoé, 13 October 2026

- When starting the game, hitting "Ready" should bring players back to the centre.
- The rules have too much text and too many slides: show, don't tell.
- When a player hit pause, the game kept running, so we all missed the flash.
- The sheep didn't reset after a memory was guessed.
- We had the UFO, but with 3 players, 3 UFOs showed up. There should be just one, on everyone's screen.
- Same with the wolf: it slid in and howled ("ahouuu") 3 times in a row.


**What we changed**

Built and checked on the test link on 13 October, live the same evening.

- "Ready to play" walks you back to the middle, and the game starting brings back anyone who didn't tap it.
- How to play: four cards, each with a little looping scene and one line, instead of eight cards of text.
- A pause before the card starts the round's look over: the glow, "Ready?", then the whole flash.
- A break before each new memory ("Ready for the next memory?"), with everyone's sheep back.
- One UFO per game on each screen, and the wolf trots in and howls once (the garden is redrawn on every change, which restarted its animation each time).
